Программа «ЭЛЮТЕК — RGB SARA-анализ» предназначена для автоматизированного визуально-оптического сопровождения жидкостно-адсорбционного разделения нефтей, фракций, битумоидов, экстрактов различных нефтезагрязнённых объектов (почв, вод и т.д.) на группы соединений. Область применения — исследовательские, производственные и учебные лаборатории, выполняющие SARA-анализ и препаративное фракционирование. Программа принимает видеопоток с камеры детектора, выделяет заданную область наблюдения, регистрирует средние значения каналов R, G и B и рассчитывает производные цветовые показатели. В реальном времени строятся графики сигнала, определяется переход между фракциями и формируются подсказки оператору. Предусмотрены ручная разметка событий, просмотр и сохранение видео, а также экспорт рядов, меток и результатов анализа в CSV и Excel. 

# ЭЛЮТЕК RGB SAR анализ

Программа для анализа RGB-сигнала с видеокамеры (USB, IP, RTSP) в реальном времени с визуализацией графиков, детекцией переходов между фракциями (SAT → AROM → BR → ABR) и экспортом данных в Excel.

## Возможности

- Захват видео с USB-камер, IP-камер, RTSP-потоков (в основном камера HuskyLens2).
- Выбор области анализа (ROI) – прямоугольник или круг.
- Предпросмотр видео с отображением ROI(области анализа) и текущих значений RGB.
- Живые графики:
  - R, G, B каналы (0–300)
  - Log10(B/R) и Log10(B/G)
  - Скорость изменения суммы RGB (RGB_sum_slope_30s)
  - Сводный индекс перехода (Transition_score)
- Автоматическая детекция переходов:
  - SAT → AROM
  - AROM → BR (с 5-минутной задержкой после AROM)
  - BR → ABR (с 5-минутной задержкой после BR)
- уведомления о переходах и статусная панель.
- Добавление текстовых меток на графиках (горячие клавиши).
- Сохранение данных в Excel (все параметры, метки, графики).
- Аварийное сохранение в CSV во время анализа.
- Запись видео анализа (в формате MKV).

## Требования

- Python 3.8 или выше.
- Windows (поддержка Linux возможна, но не тестировалась).
- FFmpeg (для работы с RTSP и записи видео) – должен быть установлен и доступен в PATH.

## Установка

Скачать и запустить "Элютек RGB SARA анализ_Setup_1.0.exe" (все необходимое для работы программы находится в установщике)

## План/новые возможности версии 1.x

- Окно «Настройки» с профилями производительности: «Экономичный», «Сбалансированный», «Производительный» и пользовательские параметры.
- Настройка частоты обработки, обновления графиков, длины истории и предпросмотра для слабых и мощных ПК.
- Анализ локальных видеофайлов (`MP4`, `AVI`, `MKV`, `MOV` и др.) теми же алгоритмами RGB/SARA.
- Регулируемая скорость воспроизведения видеофайла.
- Перемещение ROI непосредственно в окне видео во время анализа.
- Улучшено определение имён Windows-камер: сначала используется список DirectShow из FFmpeg, затем PnP как резервный вариант.
- Сохранение настроек пользователя в `%USERPROFILE%/.elutek/settings.json`.

> Защита приложения, шифрование и система ключей активации остаются отдельным следующим этапом.


## v11 changes

- All analysis graphs now use one synchronized X/time range. TRACK keeps the same visible time window on every graph; manual zoom/pan is propagated to all graphs.
- Added **Уведомления** tab to Settings.
- Automatic transition alerts/automatic annotations can be enabled/disabled.
- Thresholds and confirmation delays for SAT → AROM, AROM → BR and BR → ABR are configurable and persisted.
- Existing default detector behavior is preserved when the new settings are untouched.
- Added regression tests in `tests/test_v11_regression.py`.
