# 🔑 Генератор лицензий «Элютек: SARA RGB Анализ» (Для Администратора)

> ⚠️ **ВНИМАНИЕ:** Данная папка предназначена **ТОЛЬКО** для главного ПК администратора/заказчика.  
> **НЕ передавайте эту папку конечным клиентам!**

---

## ⚡ Быстрый запуск генератора

* Для запуска генератора ключей дважды кликните по файлу **`keygen.bat`**.
* Или запустите через Python:
  ```bash
  python keygen_gui.py
  ```
* Если нужен один переносной EXE-файл без Python: запустите `python build_keygen_exe.py` — будет создан `Keygen_Elutek.exe`.

---

## 📋 Пошаговый процесс выдачи лицензии клиенту

1. **Клиент** запускает программу на своём компьютере (даже **БЕЗ интернета**).
2. В окне программы нажимает **«🔑 Лицензия»** и сообщает вам свой **Hardware ID** (например, `ELU-D56A-9A1A-EFE1-F304`).
3. **Вы (Администратор)**:
   * Открываете приложение **`keygen.bat`**.
   * Вставляете Hardware ID клиента (кнопка *«📋 Вставить»*).
   * Выбираете тип лицензии (*PRO (Бессрочная)*, *1 Год*, *2 Года*, *5 Лет*).
   * Нажимаете **«⚡ Сгенерировать ключ»**.
   * Нажимаете **«📋 Скопировать ответ клиенту»**.
4. Отправляете скопированный текст клиенту (через WhatsApp, Telegram, Email, SMS или по телефону).
5. **Клиент** вставляет полученный ключ в окно активации и нажимает **«Активировать»** — программа мгновенно разблокируется навсегда!

---

## 🌐 Работает ли активация на ПК БЕЗ интернета?

**ДА, на 100%!**  
Программа и генератор ключей работают полностью **автономно (offline)**:
* Аппаратный ID (HWID) считывается локально с физического оборудования ПК (процессор, материнская плата, сетевой адаптер).
* Лицензионный ключ генерируется с помощью криптографической математической подписи **HMAC-SHA256**.
* Программа на ПК клиента локально проверяет математическую подпись ключа за 1 миллисекунду.
* Никаких запросов к внешним серверам или интернету **не требуется**.
* Ключ, созданный для одного ПК, физически невозможно использовать на другом компьютере.
